# 🎮 Guess My Number Game

A fun, interactive number guessing game built to practice DOM Manipulation and logic building in JavaScript!

## 🚀 Features
- 🎲 Random secret number generation (Between 1 and 20)
- 🖥️ Dynamic UI updates (messages, score, and background colors)
- 🏆 Highscore tracking that saves your best game
- 🔄 'Again!' button to reset the state without refreshing the page

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## 👨‍💻 How to Play
1. Type a number between 1 and 20 in the input box.
2. Click the **"Check!"** button.
3. Pay attention to the hints ("Too High" or "Too Low").
4. Try to guess the correct number before your score hits 0!
